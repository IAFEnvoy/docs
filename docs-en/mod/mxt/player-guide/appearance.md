# GUI Appearance

In Jupiter, open MiXianTu Client Config → Appearance → GUI Theme to select a theme.

| Theme | Appearance |
| --- | --- |
| Parchment and Cinnabar (default) | Warm paper, brown ink frames and cinnabar headings. |
| Jade and Bamboo | Pale jade panels, bamboo-green frames and dark green text. |
| Ink and Gold | Dark ink-jade panels, gold frames and light text. |

Close and reopen a screen after changing the setting. A game restart is not required. All themes share the same layout, font and slot dimensions.

The setting applies to character information, spirit crafting, trading screens, the rift editor and the profiler. AUI screens from the Alchemy, Forging and Talisman Workstations addons use the same setting. Vanilla screens, the Saturn wheel, world effects and vanilla item tooltips retain their own appearance.

Text colours supplied by auras and resources adjust in brightness for the selected background. Items, recipe colours and progress fills retain their existing meaning. All themes use Minecraft's bitmap font and require no additional fonts.
