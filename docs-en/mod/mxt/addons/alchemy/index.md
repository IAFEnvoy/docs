---
title: Alchemy Workstations Addon
---

**Alchemy Workstations** (`mxt_alchemy`) supplies an independent workstation and production workflow for MiXianTu. Install it on both client and server alongside MiXianTu and its required dependencies. All addon items appear in the **MiXianTu creative tab**.

Addon-owned blocks, menus, recipe types and data types use `mxt_alchemy:*`. No aliases or migration are provided for the former `mxt:*` IDs. The core supplies shared tools, materials, outputs and `mxt:heat_source`; datapacks or content packs define process values.
