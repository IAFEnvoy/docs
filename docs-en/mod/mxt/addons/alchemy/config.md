---
title: Alchemy Workstations Configuration
---

Alchemy Workstations requires Jupiter and loads its own server configuration at startup. Its Jupiter entry is **Alchemy Workstations**. Reading and editing the server configuration require operator permission.

There are currently no workstation-specific settings, so the first launch creates an empty object, `{}`. Furnace, wall-material and alchemy-recipe process parameters are defined by the addon's datapack entries.

Herb catch-up limits and toxicity decay are shared MiXianTu features. They remain in the [core server configuration](../../player-guide/config.md#alchemy) and also apply without this addon installed.
