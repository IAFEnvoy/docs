---
title: Forging Workstations Configuration
---

Forging Workstations requires Jupiter and loads its own server configuration at startup. Its Jupiter entry is **Forging Workstations**. Reading and editing the server configuration require operator permission.

There are currently no workstation-specific settings, so the first launch creates an empty object, `{}`. Forging blueprints, methods, tool bindings and blueprint bindings are configured through the addon's datapack entries.
