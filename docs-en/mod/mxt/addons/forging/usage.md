---
title: Using the Forge Table
---

Place `mxt_forging:forging_table` and prepare tools and blueprint items defined by this addon. Supply the materials required by the blueprint, select it, and use the striking methods offered by the tool to move the value into the target range before completing the craft. Outputs and quality use core items and quality definitions.

See the [forging tutorial](./tutorial/forge-a-treasure.md), [tool bindings](./datapack/tool_binding.md) and [blueprint bindings](./datapack/blueprint_binding.md).
