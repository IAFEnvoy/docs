---
title: Talisman Workstations Addon
---

**Talisman Workstations** (`mxt_talisman`) supplies an independent workstation and production workflow for MiXianTu. Install it on both client and server alongside MiXianTu and its required dependencies. All addon items appear in the **MiXianTu creative tab**.

Addon-owned blocks, menus, recipe types and data types use `mxt_talisman:*`. No aliases or migration are provided for the former `mxt:*` IDs. The core supplies shared tools, materials, outputs and `mxt:heat_source`; datapacks or content packs define process values.
