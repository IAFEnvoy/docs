# Tools

<span id="tools" />

The [formation figure editor](./formation-figure.md) draws `strokes` for `mxt:formation_shape` without connecting to the game. Use `Copy JSON` or `Download JSON` to export, and `Load from JSON` to continue editing an existing file.

The editor writes shapes only. Configure fields such as the particle module's `duration_ticks` in the definition.

The [talisman stroke editor](../addons/talisman/tools/talisman-strokes.md) belongs to the Talisman Workstations addon documentation.
