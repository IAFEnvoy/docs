The entity actions System provides for Saturn. They can be combined with Saturn's meta types of the same kind.

| Type | Purpose |
| --- | --- |
| [`system:add_module`](./add_module.md) | Persistently adds a module for a bound player. |
| [`system:remove_module`](./remove_module.md) | Persistently disables a module for a bound player. |
