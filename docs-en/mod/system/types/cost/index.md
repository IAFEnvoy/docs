title: "Cost types"
sidebar_position: 0
---

System provides these extensions to Saturn's cost type registry. Embed them in the `costs` arrays of shop offers, lottery pools and workshops.

| Type | Purpose |
| --- | --- |
| [`system:currency`](./currency.md) | Deducts a specified currency from the player's System wallet. |

For items, Saturn resources and combined costs, see [Saturn costs](../../../../library/saturn/types/cost.md). For the quote and payment lifecycle, see [Costs and Payment](../../../../library/saturn/guides/costs.md). Cost objects are not standalone data files.
