# Icarus

:::caution Unstable
This integration is newly implemented and currently unstable.
:::

Enabled when Icarus is installed.

## `origins_integration:wings`

[Power Type](../types/power)

Supplies a virtual Icarus wing item for normal flight logic and
rendering.

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `wing` | Resource Location | `icarus:white_feathered_wings` | Icarus wing item to emulate |
