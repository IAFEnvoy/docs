# Content Index

MITE content is organized as rules rather than as a raw configuration dump. Rule IDs follow the MITE documentation convention: a short system prefix plus a stable two-digit number. Gaps are intentional where an older rule was excluded, merged, or is not part of the current release.

Each rule starts with the setting names shown in the in-game configuration screen, followed by a player-facing description.
