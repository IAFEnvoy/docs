## What is Mixin?
Mixin is a Java library that modifies Java code at the bytecode level, in compiled class files.

For a complete description of its features, uses, and mechanisms, see the [official Mixin wiki](https://github.com/SpongePowered/Mixin/wiki). Additional documentation is available in the [Mixin Javadoc](https://jenkins.liteloader.com/view/Other/job/Mixin/javadoc/index.html).

This tutorial focuses on using Mixin. For details of its internal workings, consult the resources above. I also link to my own Mixin code on GitHub as examples.
