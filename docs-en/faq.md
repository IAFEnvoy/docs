# FAQ

## Will mod XXX still be updated?

Of the batch of mods written four years ago, only `Item Drop Protection` will still be maintained; everything else is no longer maintained. Other mods (except `Avaritia`) will be updated gradually.

## Why is mod XXX updated so slowly?

I have more than a dozen projects on hand, including my mods, so I can't cover everything.

## Can you port mod XXX to version YYY?

Only `Item Drop Protection` follows each major Minecraft version after updates end. Other mods will stay on 1.20.1 for now and be updated once there are more mods on the next version.

For library mods, you can ask me to port `Jupiter` upward (downward ports are not accepted, because I tried and it broke).

## Your mod has a bug?

Report it on the GitHub page of the corresponding project (recommended), or join the QQ group `966154502`.

## Can I put your mod in a modpack?

Yes, but it is not recommended. Some mods have strange bugs, so remember to back up your saves.

## Can I hire you to make a port?

Not for now; I have too many projects on hand. ~~But money can work miracles.~~

## The in-game account switcher doesn't work on newer versions?

Correct. The GUI code I wrote back then had problems. But I'm not a launcher developer and don't understand login logic, so even if there is a problem, I neither have the skills nor the time to maintain it.

If you need it on a newer version, try `Account X` on MCMod, made by a maintainer of HMCL.

## Avaritia XXX doesn't work / XXX has a bug?

For example, the `Endest Pearl` and some other items are not finished yet. However, I have discussed it with the author of another Avaritia (`Re: Avaritia`), and I will port that mod in the future, since its content is more complete.

## Are there plans to port Ice And Fire Fabric to Forge/NeoForge?

Yes, but not now, and I need to talk to the original author first.

## When will there be a stable version of The Twilight Forest Fabric?

Unknown. Other developers' code is too abstract; I still need to sort it out bit by bit.

## Will the sequel to the Netherite Expansion support other versions/loaders?

Someone has already been asked to work on Forge, and the Fabric port is being backported.
