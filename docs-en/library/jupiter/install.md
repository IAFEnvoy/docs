# How to install

This article will tell you how to install this library for both players and developers.

## For players

Download this mod on [CurseForge](https://www.curseforge.com/minecraft/mc-mods/jupiter).

## For developers

You can download the jar with the link above, or use [CurseMaven](https://cursemaven.com)
