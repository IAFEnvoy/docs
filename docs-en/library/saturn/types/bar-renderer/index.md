---
title: "Resource bar renderers"
sidebar_position: 0
---

Used for ResourceBar.renderer; a renderer displays the resource snapshot and does not modify the resource. Colours are written as #RRGGBB.

| Type | Purpose |
| --- | --- |
| [`saturn:textured_bar`](./textured_bar.md) | Draws the resource bar with a background and a fill texture. |
| [`saturn:segmented_bar`](./segmented_bar.md) | Represents the resource amount with multiple colour blocks. |
| [`saturn:radial_bar`](./radial_bar.md) | Draws ring progress within the given angle range. |
| [`saturn:text_only`](./text_only.md) | Shows the resource value as formatted text. |
| [`saturn:boss_bar`](./boss_bar.md) | Uses the boss bar style of the given texture. |
| [`saturn:missing`](./missing.md) | Represents a missing implementation or value. |
