MITE：重铸在 **Minecraft 1.21.1 + NeoForge 21.1** 上重建了 MITE 1.6.4 严苛的生存循环。它不只是一个添加矿石与怪物的内容模组。生命值、饥饿、营养、采集要求、限时合成、材料等级、农业、畜牧产出、月相、冥界与怪物行为共同构成一套相互关联的规则体系。

:::warning 按 MITE 的规则生存

新玩家默认只有 3 颗心和 3 个饥饿图标。徒手挖矿、跳过工作台等级，或只靠单一食物来源维生，都不是可靠的策略。进入第一个世界之前，请先阅读[流程指南](./getting-started/progression.md)。

:::

## 当前内容

- 分等级的工作台、基于热量的熔炉、按材料区分的铁砧、金属桶、额外武器与装备品质。
- 蛋白质、必需脂肪、植物营养素与胰岛素反应，并提供专门的营养界面和 HUD。
- 洋葱、蓝莓、施肥农田、作物病害，以及具有食物、饮水与活动空间需求的牲畜。
- 银、远古金属、秘银与艾德曼合金材料链；铜使用原版 Minecraft 资源。
- 冥界、三阶段的标准传送门路线、16 种符文图案，以及同维度远距离符文之门。
- MITE 亡灵、蜘蛛、蝙蝠、凝胶状怪物、元素生物，以及服务器权威 AI。
- 可选的 JEI、EMI 与 Jade 集成。
