MITE 的流程不是“先打木头，再挖矿”。采集要求、工作台、熔炉热量与材料工具互相构成门槛。下面是一条不依赖运气捷径的标准路线。

## 1. 活过第一天

1. 收集地表食物，并尽可能把肉、鱼、水果、蔬菜与乳制品搭配起来。
2. 从树叶、草与砂砾中获得木棍、燧石碎片与低等级材料。
3. 制作燧石工具。原木需要斧；石头与矿石需要镐。
4. 搭建燧石工作台，并在工作区上方留出净空。
5. 在入夜前准备好封闭的庇护所。血月会阻止睡眠，即使普通的夜晚也比原版更危险。

:::tip 检查你的营养状态

默认按 `N` 打开营养界面，或点击生存模式物品栏旁的苹果按钮。HUD 上的营养值不是原版的饱和度。只吃一种食物最终会让你的储备失衡。

:::

## 2. 获得第一批金属

- 淘洗砂砾会提供渐进式的燧石与金属碎片掉落，是前期的资源来源之一。
- 铜使用原版的铜矿、铜锭与铜块。MITE 加入了铜粒、工具、工作台、铁砧、桶与加工链。
- 银拥有自己的矿石与装备，并在对抗亡灵时有额外用途。
- 在处理矿物之前，先建好低等级熔炉，并准备足够热的燃料。正在燃烧的燃料不一定足够热。

推荐顺序：

```text
Flint -> Copper/Silver/Gold -> Iron -> Ancient Metal -> Mithril -> Adamantium
```

黑曜石是一条特殊的非金属分支。黑曜石工作台只支持燧石与黑曜石等级，不能与所有高阶工作台互换使用。

## 3. 建立生产据点

1. 升级到能够解锁更高等级配方的材料工作台。
2. 用对应的金属粒在材料铁砧上修理装备。
3. 种植小麦、胡萝卜、马铃薯、洋葱与蓝莓；保持农田湿润并用粪便施肥。
4. 为牛、猪、羊与鸡提供食物、饮水、户外空间与围栏。状态不佳的牲畜产量更低。
5. 分散风险：作物可能染病、动物可能恐慌，而血月会同时加重农业与战斗压力。

## 4. 进入冥界

标准黑曜石传送门会依据所在维度与框架地基走一条固定的路线：

```text
Overworld -> Underworld -> Nether
```

冥界以深板岩洞穴、密集矿脉、基岩地形以及 Y=27 至 32 附近起伏的地幔为中心。不要垂直向下挖掘：地幔地形会点燃周围空间，而深处的生物远强于前期的主世界怪物。

## 5. 符文之门与后期

- 秘银与艾德曼合金符文石各有 16 种图案。
- 右键点击合成输出槽可切换图案。
- 点亮一个黑曜石传送门，并在四个角放置同种材料的符文石，即可形成符文之门。
- 四种图案的组合决定了当前维度内一个稳定、远距离的目的地。符文之门不跨越维度，也不会创建返回传送门。
- 艾德曼合金符文之门的半径至少是秘银之门的八倍，其目的地距离出生点至少 20,000 格。

在后期，装备品质、附魔、材料箭矢、月相生成与村庄解锁共同决定效率。配方查看器会显示当前服务器配置未禁用的配方，但它们不能绕过工作台、技能或生存状态的要求。
