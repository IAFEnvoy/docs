## 冥界

`mite:underworld` 冥界是一个独立维度，而不是主世界洞穴的复制品。它的主要特征包括：

- 以深板岩为基础岩石，矿脉密集，地牢与蜘蛛网独立生成。
- 封闭的天花板与噪声塑形的基岩分层，避免出现大片悬浮基岩与无限制的峡谷。
- 以下层基岩变化为中心的地幔地形，通常在 Y=27 至 32 附近起伏。
- 周期性迷雾、危险的实体，以及通往下一站下界的下一阶段标准传送门。

游戏内配置界面提供冥界总开关，以及各自独立的地牢、迷雾、基岩分层、地形噪声、蜘蛛网与传送门路由设置。

:::warning 世界生成设置

更改维度或矿石生成规则不会重写已有的区块。请先备份世界，并在新世界或尚未探索的地形中测试。

:::

## 矿石生成

MITE 使用原版铜资源，同时调整铜的生成并加入银、秘银与艾德曼合金矿石。每种矿石都有可见的生成、区块尝试次数、矿脉大小与高度范围设置。完整规则摘要见 [WLD-01](../content/world-and-ecology.md#wld-01)。

## 标准传送门路线

传送门的目标取决于当前维度与其框架下方的地基方块。默认路线为：

```text
Overworld -> Underworld -> Nether
```

来源维度、地基选择器、目标与颜色在 `config/mite/portals/*.json` 中定义。替换主世界传送门下方的地基会立即更新其颜色。

## 符文之门

当点亮的黑曜石传送门四个角都使用同种材料的符文石时，它就会变成符文之门。秘银与艾德曼合金符文石各有 16 种图案：Nul、Quas、Por、An、Nox、Flam、Vas、Des、Ort、Tym、Corp、Lor、Mani、Jux、Ylem 与 Sanct。

- 右键点击合成输出槽可循环切换图案。
- 四角的图案与朝向共同决定一个稳定的目的地。
- 目的地以玩家在当前维度的重生点为准，没有有效重生点时回退到世界出生点。
- 符文之门只在当前维度内传送，并且不会创建返回传送门。
- 主世界的目的地会避开海洋；下界与其他目的地会搜索安全的落点。
- 传送延迟由服务器计时并执行。客户端只是把该计时映射到原版下界传送门的遮罩上。

相关设置为 **Enable Rune Gates**、**Rune Gate teleport delay**、**Mithril Rune Gate domain radius** 与 **Adamantium Rune Gate domain radius**。角部方块与半径配置在 `config/mite/rune_gates` 中定义。

## 月相事件

- 血月通常每 32 天出现一次。它会在白天强制雷暴、在夜间阻止睡眠、提高作物病害风险、强化敌对生物，并使用红色的月面与光晕。
- 蓝月通常每 128 天出现一次，并让整个白天保持晴朗。夜间它会降低地表的敌对生物生成、补充动物数量、在非专用服务器的世界中加速作物生长，并使用蓝色的月面与光晕。
- 收获之月与幻月分别在血月和蓝月之前配置的偏移天数出现。它们目前提供特殊的月相配色，幻月还会渲染一圈淡色光环。
- 原版的满月与新月保留各自独立的地表生成概率设置。
- 每种特殊月相都有自己的地表生成概率。

总开关为 **Enable moon events** 与 **Enable MITE moon-based surface spawning**。
