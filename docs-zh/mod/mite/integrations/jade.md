Jade 集成是可选的。MITE 插件扩展了 Jade 原版的名称、容器、生命值、作物与熔炉组件，但不会重绘它们的基础信息。

## 显示的信息

| 提供方分组 | 目标 | 信息 |
|---|---|---|
| MITE 熔炉状态 | 5 种 MITE 熔炉 | 剩余燃料/冶炼秒数、当前/最大热量、输入要求、不兼容情况 |
| MITE 农业状态 | 作物与农田 | 已死亡、患病、已施肥；死亡作物会省略容易误导的成熟度 |
| MITE 方块详情 | 工作台、符文石、保险箱 | 工作台等级、符文名称、所有者、锁定状态 |
| MITE 牲畜状态 | 牛、猪、羊、鸡 | 食物、饮水、自由、粪便时间、牛奶、羽毛、产出进度 |
| MITE 怪物状态 | 大地元素与凝胶状怪物 | 热量/熔融阈值、已溶解方块数量、最近完成时间 |

每个提供方分组都可以在 Jade 的插件设置中单独禁用。鸡的详细产出阈值遵循 Jade 的“显示详情”设置。

## 客户端与服务器

客户端可以直接从方块状态读取工作台等级、符文与施肥状态。以下由服务器裁决的数值使用 Jade 的按需请求/响应通道：

- 内部熔炉计时与热量。
- 保存在存档数据中的作物病害。
- 牲畜状态与产出倒计时。
- 保险箱所有者与访问结果。
- 大地元素的内部热量与凝胶状溶解进度。

服务器不会持续广播这些数据。只有当玩家看向目标时，Jade 才会请求它。

:::tip 建议的安装方式

单人游戏按常规方式安装 Jade 即可。在专用服务器上，请同时在客户端与服务器安装 Jade 15.9+；否则只能获得客户端已知的基础信息。

:::
