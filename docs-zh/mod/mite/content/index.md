# 内容索引

MITE 的内容按规则组织，而不是把配置项原样罗列。规则 ID 遵循 MITE 文档约定：一个简短的系统前缀加一个稳定的两位数编号。某些编号的缺失是有意的，表示旧规则已被排除、合并，或不属于当前版本。

每条规则先列出游戏内配置界面中显示的设置名称，再给出面向玩家的说明。
