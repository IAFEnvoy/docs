## 年龄与寿元 {#age}

寿元账本记录剩余寿元与本世总寿元，单位均为游戏刻。年龄等于总寿元减去剩余寿元。给有限寿元增寿时，两者同步增加，年龄保持不变。档案和 `/lifespan get` 以**年龄 / 总寿元**显示，默认将 `24000` 刻换算为一岁。

自然老化默认关闭。开启「寿元」配置后，玩家获得设定的初始寿元。默认每隔 `20` 游戏刻，从正在 tick 且具有有限账本的存活实体扣除 `20` 刻寿元。玩家离线时不老化，创造与旁观模式默认也不老化。普通生物可以通过[指令](./commands.md#lifespan)、[数据包行为](./datapack.md#actions)或脚本获得寿元。

常规死亡重生会保留同一世账本。开启自然老化时，完整换世会重新初始化新一世的寿元。显式原地重置会按初始值重新记账，即使自然老化已关闭。`/lifespan unlimited` 可关闭账本，随后可用 `set` 或正值 `add` 重开有限寿元。

## 寿元耗尽 {#expiry}

| 选项 | 作用 |
| --- | --- |
| `none` | 关闭账本并发送耗尽事件。 |
| `death` | 以 `reincarnation:lifespan` 伤害击杀实体。玩家也可配置为切换到旁观模式。玩家因寿元伤害死亡后走常规死亡重生流程，已开启的死亡自动转生可在重生时触发。 |
| `reincarnate` | 使用配置的玩家转生模式。**完整换世**会归档并替换玩家。**原地重置**保留实体和世数，按[保留规则](./datapack.md#attachment-retention)处理附件并重新初始化寿元。其他生物原地重置。 |

需要拦截耗尽或在耗尽时续命时，可使用[耗尽事件](./kubejs.md#events)。

## 配置项 {#settings}

下列键位于[服务端配置](./index.md#server-configuration)的 `lifespan` 分组。

| 配置项 | 默认 | 作用 |
| --- | --- | --- |
| `enabled` | 关闭 | 开启自动授予、自然老化、耗尽结算与低寿元提醒。 |
| `base_lifespan` | `1440000` | 初始寿元刻数，按默认单位显示为 60 岁。设为零时不自动授予有限寿元。 |
| `settle_interval` | `20` | 结算间隔，单位为游戏刻。 |
| `age_per_settle` | `20` | 每次结算扣除的寿元刻数，设为零时年龄停止增长。 |
| `on_expire` | `death` | 剩余寿元到零时的处理方式。 |
| `player_death_mode` | `kill` | 击杀玩家或切换至旁观。 |
| `player_rebirth_mode` | `new_life` | 选择完整换世或原地重置。 |
| `warning_fraction` | `0.1` | 剩余与总寿元之比达到或低于此值时提醒一次，回到阈值之上后可再次触发。设为零时关闭。 |
| `ticks_per_year` | `24000` | 仅用于显示换算，设为 `1` 时显示刻数。 |
| `age_creative` | 关闭 | 是否为创造模式玩家结算老化。 |
| `age_spectator` | 关闭 | 是否为旁观模式玩家结算老化。 |
| `kill_on_reset` | 关闭 | 在原地重置后对实体施加寿元伤害。 |
