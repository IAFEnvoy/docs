# 常见问题

## 为什么 Forge 版本只在 GitHub 上发布？
* 尽管原版模组很少更新，但它并未停止维护，并且仍会为原开发者带来收益。CE 的开发者无法联系到原开发者，讨论自己是否被允许发布这个模组。当 CE 变得更受欢迎时，就会开始“抢占”原版模组的下载量，这可能引发问题。除非原版模组正式停止维护，否则 CE 的 Forge 版本将只留在 GitHub 上，以免与其竞争。

## 我可以从官方版本升级到 CE 吗？
* 有时可以，有时不行。不提供任何保证。尝试之前请务必做好备份。

## 为什么移除了蚁族？
* 原版模组中的蚁族问题非常多，无法正常工作，有时还会导致崩溃。CE 的开发者只是出于爱好制作这个模组，没有时间完全重写它们，因为单纯修复并不可行。在完成重写之前，他决定完全移除蚁族，以免所有人都来问他相关的错误——这些错误他早已清楚。

## 为什么新增的配方是独立分开的（IaF: Smithing 附加包）？
* 这是由该模组的社区决定的，目的是让人们可以在两种方式之间选择，因为新方式获取难度高得多，而许多人喜爱冰火传说正是因为能早早获得好装备。添加这些配方的附加包有两个版本：数据包和模组。它由另一位开发者开发，但仍属于半官方性质，并获得了 CE 开发者的认可。

## 有计划添加冰火传说中未使用的内容吗？
* 其中一些肯定会添加，但目前尚未进入开发阶段。首先必须完成所有内部重写和修复。

## 原版冰火传说的附加包能在 IaF:CE 上使用吗？
* 不能，大多数附加包都无法使用，因为它们甚至不在正确的加载器上。但如果它们是基于 Fabric 和 1.21.1 版本的，那它们肯定支持 CE。目前共有 3 个附加包：[Ice and Fire Dragons X Better Combat](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons-x-better-combat)、Ice And Fire Smithing、[Dragon Survival: IAF Integration](https://www.curseforge.com/minecraft/mc-mods/dragon-survival-iaf-integration)
