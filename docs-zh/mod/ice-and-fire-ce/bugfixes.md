# 错误修复

## 生物

- 修复了龙吐息时卡顿的问题。
- 扩展了龙类型 API。
- 修复了戈尔贡破坏所有盔甲的问题。
- 修复了与石化状态相关的崩溃。

### 多部件重写

- 修复了多部件实体卡顿的问题。
- 修复了多部件实体刷屏日志的问题。

## 世界生成

- 修复了陵墓的方块可以被破坏的问题。

* ### 结构系统重写

	- 将世界生成系统切换为原版实现。
	- 修复了龙巢穴被切断的问题。
	- 修复了与 Distance Horizons 的冲突。
	- 修复了与 c2me 的冲突。
	- 修复了在世界边界处崩溃的问题。

## 模组兼容

- 为 Jade 添加了更好的兼容，并修复了多部件实体的信息显示问题。
- 添加了 EMI 支持。

## 渲染

- 修复了龙长时间吐息后龙息渲染过长的问题。
- 修复了盔甲有时渲染错误的问题。
- 增强了标题界面的渲染能力。

* ### Tabula 模型加载器重写

	- 修复了 Tabula 模型在特定环境（例如开发模式）下无法正确加载的问题。
