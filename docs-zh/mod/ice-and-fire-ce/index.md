# 冰火传说社区版

**冰火传说社区版（Ice And Fire: Community Edition）** 是[冰火传说](https://www.curseforge.com/minecraft/mc-mods/ice-and-fire-dragons)模组的非官方分支。

Fabric 和 NeoForge 版本可在 [CurseForge](https://www.curseforge.com/minecraft/mc-mods/iceandfire-ce) 下载。**Forge 版本仅在 [GitHub](https://github.com/IAFEnvoy/IceAndFire-CE/releases) 发布。**

## 与原版的区别

- 保留原版的所有内容，**蚁族除外**（参见[常见问题](faq)）。
- 支持 Minecraft 1.21.1 和 1.20.1，提供 Fabric、NeoForge 与 Forge 版本；原版最高支持 1.20.1，且仅支持 Forge 和 NeoForge。
- 包含新增功能、模组兼容、代码重写、错误修复和性能优化。
