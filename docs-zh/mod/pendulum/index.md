# Pendulum

Minecraft 客户端 JavaScript 执行器，让操作自动化。

支持 **Fabric 1.20.1/1.21.1**、**Forge 1.20.1** 和 **NeoForge 1.21.1**。
版本兼容信息见[安装](installation)。

**同时支持玩家脚本和通过 MCP 接入的 AI 智能体。**

本模组的设计深受浏览器自动化框架 `Playwright.js` 启发。
