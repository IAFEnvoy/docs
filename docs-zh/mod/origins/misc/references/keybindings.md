# 按键绑定 {#keybindings}

### Origins 按键绑定 {#origins-keybindings}

| 标识符 | 游戏内名称 | 默认值 |
|------------|--------------|---------|
| `key.origins.primary_active` | 主动能力（主要） | `G` |
| `key.origins.secondary_active` | 主动能力（次要） | *未绑定* |
| `key.origins.view_origin` | 查看起源 | `O` |
