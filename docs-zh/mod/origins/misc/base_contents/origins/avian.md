# 羽人族

**影响等级：** <span style={{color:'green'}}>1（低）</span> | **排序：** 0 | **图标：** 羽毛

羽人族早已失去飞行的能力。如今，这些和平的生物只能从一个地方滑翔到另一个地方。

---

| 名称 | 能力 ID | 描述 |

| 轻如羽毛 | `origins:slow_falling` | 你像羽毛一样轻缓下落，不会受到任何摔落伤害。 |
| 新鲜空气 | `origins:fresh_air` | 睡觉时，你的床必须位于至少 86 格的高度才能让你呼吸。 |

| 卵生 | `origins:lay_eggs` | 每当你在早晨醒来时，都会产下一枚蛋。 |
