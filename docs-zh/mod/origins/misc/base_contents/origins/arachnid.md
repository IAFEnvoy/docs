# 蛛形族

**影响等级：** <span style={{color:'green'}}>1（低）</span> | **排序：** 1 | **图标：** 蜘蛛网

它们的攀爬能力以及把敌人困在蛛网中的手段，使蛛形族成为完美的猎手。

---

| 名称 | 能力 ID | 描述 |

| 蛛网大师 | `origins:master_of_webs/webbing` | 你可以用主要主动能力键把敌人困在蛛网中。 |
