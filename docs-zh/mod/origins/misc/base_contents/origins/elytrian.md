# 翼人族

**影响等级：** <span style={{color:'green'}}>1（低）</span> | **排序：** 3 | **图标：** 鞘翅

翼人族常年在风中飞行，当头顶上方没有足够空间时，它们会感到不适。

---

## 能力

| 名称 | 能力 ID | 描述 |
|------|----------|-------------|
| 有翼 | `origins:elytra` | 你拥有鞘翅翅膀，无需装备任何物品。 |
| 风之赐福 | `origins:launch_into_air` | 每 30 秒，你可以将自己弹射到约 20 格高的空中。 |
| 空中战斗者 | `origins:aerial_combatant` | 在鞘翅飞行时，你造成的伤害大幅提高。 |
| 机动需求 | `origins:light_armor` | 你不能穿戴任何重型盔甲（护甲值高于锁链盔甲的盔甲）。 |
| 幽闭恐惧 | `origins:claustrophobia` | 长时间待在天花板过低的地方会使你虚弱并变慢。 |
| 脆弱骨骼 | `origins:more_kinetic_damage` | 你因摔落和撞上方块而受到的伤害更高。 |
