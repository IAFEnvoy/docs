# 烈焰族

**影响等级：** <span style={{color:'red'}}>3（高）</span> | **排序：** 1 | **图标：** 烈焰粉

作为烈焰人的后裔，烈焰族天然免疫下界的种种危险。

---

## 能力

| 名称 | 能力 ID | 描述 |
|------|----------|-------------|
| 火焰免疫 | `origins:fire_immunity` | 你免疫所有类型的火焰伤害。 |
| 下界居民 | `origins:nether_spawn` | 你的自然生成位置将在下界。 |
| 燃烧之怒 | `origins:burning_wrath` | 当你着火时，你的攻击会造成额外伤害。 |
| 热血 | `origins:hotblooded` | 由于你的身体炽热，毒素会被烧尽，因此你免疫中毒和饥饿状态效果。 |
| 恐水 | `origins:water_vulnerability` | 与水接触时，你会持续受到伤害。 |
| 火焰粒子 | `origins:flame_particles` | 火焰粒子环绕着你。 |
