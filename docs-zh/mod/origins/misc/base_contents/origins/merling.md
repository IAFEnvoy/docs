# 人鱼族

**影响等级：** <span style={{color:'red'}}>3（高）</span> | **排序：** 0 | **图标：** 生鳕鱼

这些海洋的原住民不习惯长时间离开水域。

---

## 能力

| 名称 | 能力 ID | 描述 |
|------|----------|-------------|
| 鳃 | `origins:water_breathing` | 你可以在水下呼吸，但无法在陆地上呼吸。 |
| 水下视觉 | `origins:water_vision/water_vision` | 你在水下的视觉完全正常。 |
| 水下视觉 | `origins:water_vision/night_vision` | 你在水下可以在黑暗中视物。 |
| 水下速掘 | `origins:aqua_affinity/underwater` | 你在水下破坏方块可以像其他人在陆地上一样。 |
| 水下速掘 | `origins:aqua_affinity/ungrounded` | 你破坏方块时也不会受到未站在地面上的惩罚。 |
| 鱼鳍 | `origins:swim_speed` | 你的水下速度提高。 |
| 如水般 | `origins:like_water` | 对行走速度的修正也会在你浸入水中时生效。 |
| 潮涌能量 | `origins:conduit_power_on_land` | 在陆地上时，你可以从空气中获得潮涌能量。 |
