# 末影族

**影响等级：** <span style={{color:'orange'}}>2（中）</span> | **排序：** 1 | **图标：** 末影珍珠

末影族作为末影龙的后裔，能够传送，但惧怕水。

---

## 能力

| 名称 | 能力 ID | 描述 |
|------|----------|-------------|
| 传送 | `origins:throw_ender_pearl` | 你可以随时投掷一颗不造成伤害的末影珍珠，以此传送。 |
| 恐水 | `origins:water_vulnerability` | 与水接触时，你会持续受到伤害。 |
| 惧怕葫芦 | `origins:pumpkin_hate/prevent_eating` | 你不能吃与南瓜相关的食物。 |
| 惧怕葫芦 | `origins:pumpkin_hate/prevent_seeing` | 当玩家头戴雕刻南瓜时，你看不到该玩家。 |
| 纤细身躯 | `origins:extra_reach` | 你可以够到更远的方块和实体。 |
| 末影粒子 | `origins:ender_particles` | 末影粒子环绕着你。 |
