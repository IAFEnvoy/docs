# 潜影族

**影响等级：** <span style={{color:'green'}}>1（低）</span> | **排序：** 4 | **图标：** 潜影壳

潜影族与潜影贝有关，它们的身体覆盖着一层具有保护作用的壳状皮肤。

---

## 能力

| 名称 | 能力 ID | 描述 |
|------|----------|-------------|
| 囤积者 | `origins:shulker_inventory` | 你拥有额外的 9 个物品栏槽位，死亡后仍会保留。 |
| 坚硬皮肤 | `origins:natural_armor` | 即使不穿戴盔甲，你的皮肤也能提供天然防护。 |
| 强壮手臂 | `origins:strong_arms/break_speed` | 你无需镐即可破坏自然石头。 |
| 强壮手臂 | `origins:strong_arms/break_stone` | 破坏自然石头的速度提高。 |
| 无盾 | `origins:no_shield` | 你的副手无法持有盾牌。 |
| 大胃口 | `origins:more_exhaustion` | 你的饥饿值消耗比其他生物快得多，因此需要吃更多食物。 |
