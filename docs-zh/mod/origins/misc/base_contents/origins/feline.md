# 猫族

**影响等级：** <span style={{color:'orange'}}>2（中）</span> | **排序：** 0 | **图标：** 橙色羊毛

凭借猫一般的外表，猫族能吓退苦力怕。凭借猫的灵巧，它们总能安然落地。

---

## 能力

| 名称 | 能力 ID | 描述 |
|------|----------|-------------|
| 杂技 | `origins:fall_immunity` | 你永远不会受到摔落伤害，无论从多高的地方落下。 |
| 强壮脚踝 | `origins:sprint_jump` | 你可以在冲刺时跳跃，从而跳得更高。 |
| 天鹅绒肉垫 | `origins:velvet_paws` | 你的脚步不会引起振动，也不会发出脚步声。 |
| 九命 | `origins:nine_lives` | 你的生命值比人类少 1 颗心。 |
| 虚弱手臂 | `origins:weak_arms` | 在未受力量药水影响时，你挖掘自然石头的速度更慢。 |
| 猫形外表 | `origins:scare_creepers` | 苦力怕惧怕你，只有在你先攻击它们时才会爆炸。 |
| 夜行性 | `origins:cat_vision` | 不在水中时，你可以在黑暗中勉强看清。 |
