# 幻影族

**影响等级：** <span style={{color:'red'}}>3（高）</span> | **排序：** 2 | **图标：** 幻翼膜

作为半人半幻翼的生物，幻影族可以在幻翼形态与普通形态之间切换。

---

## 能力

| 名称 | 能力 ID | 描述 |
|------|----------|-------------|
| 幻影化 | `origins:phantomize/toggle` | 你可以用主要主动能力键随意在人类形态和幻翼形态之间切换。 |
| 幻影化覆盖层 | `origins:phantomize/overlay/green` | 幻影化时，会出现一层绿色覆盖层。 |
| 半透明 | `origins:translucent` | 幻影化时，你的身体会变成半透明。 |
| 相位穿行 | `origins:phasing` | 幻影化时，你可以穿过固体方块（`origins:unphasable` 方块标签中的方块除外）。 |
| 隐身 | `origins:invisibility` | 幻影化时，其他玩家和生物看不到你。 |
| 光过敏 | `origins:burn_in_daylight` | 如果你未处于隐身状态，日光下你会开始燃烧。 |
| 快速代谢 | `origins:hunger_over_time` | 处于幻影化状态会随时间消耗你的饥饿值。 |
| 脆弱 | `origins:fragile` | 你的生命值比人类少 3 颗心。 |
