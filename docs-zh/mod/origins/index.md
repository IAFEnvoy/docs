# 起源（NeoForge）

欢迎阅读起源（NeoForge）文档！本模组允许玩家在游戏开始时选择一个**起源**，从而获得独特的能力与特性。

:::info
本模组是原版起源模组的完整重写版本，构建于 NeoForge 之上。原版模组的某些 API 和功能可能不存在于本版本中，部分行为也可能不同。

有关如何使用新系统的详细信息，请参阅文档。
:::

## 下载

[CurseForge](https://www.curseforge.com/minecraft/mc-mods/origins-neoforge) | [源代码](https://github.com/IAFEnvoy/Origins-NeoForge)

你还需要安装 [Jupiter](../../library/jupiter/)。

- 起源、能力、起源层和徽章均可通过**[数据包](./guides/datapack/define_origin)**配置
- 所有 JSON 格式都记录在 **[JSON 数据格式](./json/origin)**中
- 类型系统在**[基本概念](./types/basic_concepts)**、**[共享数据类型](./types/shared_data_types)**和 **[Minecraft 数据类型](./types/minecraft_data_types)**中介绍
- 条件与动作类型列在**[类型参考](./types)**中
- KubeJS 扩展文档：**[起源JS](./js)**
