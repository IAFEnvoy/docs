| 字段 | 类型 | 默认值 | 说明 |
|-------|------|---------|-------------|
| `name` | [文本组件](/zh/docs/mod/origins/types/minecraft_data_types#text-component) | 可选 | 起源的显示名称。更推荐使用翻译键 `origin.<namespace>.<path>.name` |
| `description` | [文本组件](/zh/docs/mod/origins/types/minecraft_data_types#text-component) | 可选 | 起源提示框中显示的描述。更推荐使用翻译键 `origin.<namespace>.<path>.description` |
| `powers` | [引用或标签列表](/zh/docs/mod/origins/types/basic_concepts#referenceortaglist) | `[]` | 此起源授予的能力 ID 或标签。使用 `"origins:xxx"` 或 `"#origins:tag_name"` |
| `icon` | [物品堆叠](/zh/docs/mod/origins/types/minecraft_data_types#item-stack) | 可选 | 在选择界面中作为起源图标显示的物品 |
| `unchoosable` | 布尔值 | `false` | 若为 `true`，此起源不会出现在选择界面中，但仍可通过命令或升级分配 |
| `order` | 整数 | `Integer.MAX_VALUE` | 选择界面中的排序顺序；数值越小越靠前 |
| `impact` | 整数 | `0` | 影响等级：`0` = NONE，`1` = LOW，`2` = MEDIUM，`3` = HIGH |
| `upgrades` | [Upgrade](/zh/docs/mod/origins/json/origin#upgrade-format) 对象列表 | `[]` | 起源升级配置列表 |
