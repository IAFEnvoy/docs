# 能力类型

能力类型决定了能力实际执行什么功能。通过能力 JSON 中的 `type` 字段指定。

| 类别 | 说明 | 页面 |
|------|------|------|
| 动作 | 响应事件执行动作 | [动作能力](./action) |
| 修改 | 修改属性、伤害、速度等游戏机制 | [修改能力](./modify) |
| 阻止 | 阻止使用物品、睡觉等特定行为 | [阻止能力](./prevent) |
| 常规 | 飞行、隐身、穿墙等独立能力 | [常规能力](./regular) |

---

## 共享数据类型

多个能力、动作和条件共用的复杂类型。完整说明见 **[共享数据类型](../shared_data_types)**：

- **HudRender** — HUD 栏显示设置
- **Key** — 按键绑定设置
- **Modifier** — 数值修饰器
- **AttributeEntry** — 属性修饰器条目
- **PositionedItemStack** — 带可选槽位位置信息的物品
- **ColorSettings** — RGBA 颜色配置
