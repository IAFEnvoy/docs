# progression（进度链）

<span id="progression" />

文件位置：`data/<namespace>/mxt/progression/<path>.json`

`progression` 定义进度链中的单个等级。等级通过 `next_level` 连接为线性链，未被其他等级引用的等级为入口，链本身无独立身份字段。多个[功法](./technique.md)或[生物档案](./creature_profile.md)可共用同一条链，各自在 `default_level` 中指定入口；晋升所需熟练度与伤害倍率由等级定义。

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `next_level` | 下一级 id | 无 | 链上的下一级，最高一级省略。 |
| `mastery` | `NumberProvider` | `0` | 到达该级所需的熟练度。 |
| `damage_multiplier` | Double | `1.0` | 该等级的伤害倍率。 |

`mastery` 由等级定义，共用该链的所有者使用相同门槛。该值支持公式；若任一下一级的门槛低于上一级，链会被拒绝。晋升要求所有者的 `mastery_resource` 达到该值，且其为该等级配置的 `condition` 成立；`0` 表示无熟练度要求。

晋升不需要谁来驱动：主循环每 20 tick 对每个已加载生物问一次它持有的每个所有者，两个门槛都过了就顺着链往上走（不跳级），随后重算它授予的能力并发一次 `mxt:progression_level` 信号（上下文带 `owner` 与 `level`）。功法与灵宠走的是同一条检查。

`damage_multiplier` 必须为有限且非负的数值，**对所有所有者一视同仁**：施放能力时按"授予该能力、且持有者当前所在的对应等级"取倍率，以公式变量 `damage_multiplier` 注入这次施放（多个所有者都授予同一能力时取最高的那个）；伤害管线的第一层在攻击方结算时读取并相乘。生物身上的触发式能力走的是同一条施放路径，所以灵宠用它被授予的能力打出的伤害同样吃这个倍率。因此它只作用于**该链授予的能力打出的伤害**（包括该能力打在自己身上的反噬），不会给持有者的一切伤害加 buff；由诅咒、时间线、物品绑定这类非施放路径产生的伤害，上下文里没有这个值，自然也不受影响。

写法与 `realm_stage` 同形：一个单向 `next` 指针串成一条链。区别在于链由链接本身推出来、不需要额外的链身份字段，因此多个所有者可以共享同一条链。

`next_level` 与 `next_realm` 一样只是条目引用，链的顺序在运行期由链本身推导：服务器启动或数据包重载时，把"没有任何一级指向它"的对应等级当作链的第一级，沿 `next_level` 依次编号（第一级为 `0`），于是任意两级都能比较先后。成环、被两处写成后继（分叉）都会让该链的重建失败——与境界链一样，重建失败时宁可拒绝，也不留下顺序不全的链。**指向不存在的等级走不到这一步**：`next_level` 是注册表引用，指到一个当前包没有的等级会让整个数据包加载失败，不是运行期拒绝。重建还会拒绝 `mastery` 沿链下降的链条：晋升只会拿"下一级"做比较，所以下一级的要求不能比上一级更低。解析期只能拒绝本条目自身的问题（例如非法的 `damage_multiplier`）。

包改了某个所有者的入口等级之后，身体里那条再也走不到的记录会在**实体加入世界时**、玩家登录时与数据包重载时被清掉（重载扫的是全部已加载实体，生物没有"登录"这回事），该所有者退回它自己的入口等级；这道检查不在每次读取时执行，每清一条会在日志里打一条 `WARN`（带所有者与等级 id）。

**读当前等级**用实体条件 `mxt:progression`（见 [实体条件类型](../types/condition/entity_condition_types.md)）：`level` 点名一级，`comparison` 取 `==`（默认）、`!=`、`<`、`<=`、`>` 或 `>=`（与 `mxt:realm` 同一套取值，比较的是链内序号），可选的 `owner` 把问题限定到某些所有者——它写所有者定义的 id，可以写一个或一串，省略就问这个身体持有的每一种进度，任一命中即成立。它读的是持有者**到达过的对应等级**（没有晋升过就是所有者的 `default_level`），所以 `>=` 一旦成立就不会因为之后的变化变回假；没有 `default_level`、或链顺序没能重建出来的所有者永远返回 `false`。

```json
// data/example/mxt/progression/sword_art_1.json
{
  "next_level": "example:sword_art_2",
  "mastery": 0,
  "damage_multiplier": 1.1
}
```
