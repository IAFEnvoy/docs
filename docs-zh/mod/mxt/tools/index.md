# 工具

<span id="工具" />

[阵法图形编辑器](./formation-figure.md)可以绘制 `mxt:formation_shape` 的 `strokes`，不连接游戏。使用 `Copy JSON` 或 `Download JSON` 导出，`Load from JSON` 可继续编辑已有文件。

编辑器只负责形状，粒子模块的 `duration_ticks` 等字段仍需在定义中配置。

画符配方使用的[符箓笔画编辑器](../addons/talisman/tools/talisman-strokes.md)收在画符工作站附属目录中。
