---
title: 画符工作站附属
---

**Talisman Workstations**（`mxt_talisman`）为 MiXianTu 提供独立的工作站与生产流程。客户端和服务端均需安装本附属、MiXianTu 及其必需前置。所有附属物品仍加入 **MiXianTu 创造模式物品栏**。

本附属自有的方块、菜单、配方类型与数据类型均使用 `mxt_talisman:*`，不提供旧 `mxt:*` ID 的别名或迁移。共享工具、材料、产物与 `mxt:heat_source` 由本体提供，具体工艺数值由数据包或内容包定义。
