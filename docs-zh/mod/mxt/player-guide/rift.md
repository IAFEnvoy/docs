# 裂隙

<span id="裂隙" />

裂隙是一扇独立于方块的平面传送门。轮廓由局部二维顶点组成，支持凹多边形与任意朝向；不会替换门框、楼梯或半砖。墙体仍会遮挡门面，传送门不会挖空墙壁。

门的完整数据保存到实际轮廓包围盒中心所在区块，维度保留定位索引。移动或调整形状使中心跨区块时会自动转移；只重设编辑原点而不改变实际轮廓，不会改变存储归属。跨区块的门只要还有边缘区块加载，就保持整扇门有效；全部相关区块卸载后释放运行时缓存，再次加载时恢复。有限时长不会因区块卸载暂停，到期和删除都不会让旧记录在重载后复活。已有平面门会自动转存，保留身份、期限与目的地。

## 创建与编辑 {#创建与编辑}

创建、编辑、删除和导出需要 **2 级 OP**。普通玩家可以使用秘境令牌召门，也能通过已启用的门。

| 入口 | 行为 |
| --- | --- |
| `mxt:rift_anchor`、`mxt:rift` 对方块使用 | 未选中已有门时，按物品参数在点击的方块面直接放置裂隙；不消耗物品，可连续放置。 |
| 编辑物品对空气使用 | 未选中已有门时打开物品参数编辑器，主手和副手均支持。 |
| 潜行使用编辑物品 | 记录当前位置、维度与视角为目的地。 |
| 对准门面使用编辑物品 | 打开 16 格内视线上最近且未被方块遮挡的门，正反面都可选；门后有方块也能选中。也可用 `/mxt rift edit <id>`。 |
| `/mxt rift edit` | 创建草稿，默认禁用，提交后才发布。 |
| 秘境令牌 | 在前方召唤入口；人在秘境中时召唤返回门。 |

编辑器以画布为主体，左侧窄属性栏独立滚动，顶部放常用绘制工具与「文件、编辑」菜单。「文件」提供蓝图、导入、导出与另存；「编辑」提供撤销、重做、还原草稿与重新载入。形状、位置、目的地、外观、属性栏显示和世界预览/编辑优先横排显示，只有放不下的末尾按钮收进「更多」菜单，窗口变宽时自动展开。关闭与应用固定在右上角，按钮使用紧凑尺寸。

画布随窗口和属性栏伸展，不限制固定比例。「适应轮廓」把当前形状居中并调整缩放；隐藏属性栏可继续扩大绘制区域。形状属性分为「生成、顶点、变换、曲线」，每次只显示一组工具。删除门位于位置属性。菜单支持再次点击、点击外部或按 Esc 关闭，菜单展开时点击不会穿透到画布。

浮点数显示三位小数，坐标拆为 X / Y / Z 三个输入；未编辑的数值保留原始精度。复选框控制启用、安全落点等开关，目的地类型与样式通过下拉框选择。画布滚轮缩放，右键拖动平移，Shift 配合选择工具多选。几何信息与操作结果在底部分行显示。

空气使用打开的编辑器显示「物品参数」和「保存参数」：保存只修改当时使用的物品，不在世界生成门。关闭界面后点击方块，轮廓、外观、目的地、时长和启用状态沿用物品参数，位置与朝向以点击的方块面为准；编辑器里的位置仅供预览。没有保存过参数的物品默认放置启用的门。编辑期间替换物品或从外部改动参数会拒绝保存，需重新打开。

瞄准已有门或用命令打开的是世界编辑器，「应用」直接更新世界门。命令新建的草稿默认禁用，需要勾选启用才显示并允许通行；保存禁用门会明确提示当前状态。菜单展开时也可直接点击关闭或应用。

## 目的地与传送 {#目的地与传送}

| 类型 | 行为 |
| --- | --- |
| `position` | 指定维度和坐标，可选 yaw、pitch；`nearby=false` 只尝试指定位置，`true` 在各轴偏移 4 格内寻找安全位置。 |
| `secret_realm` | 选择秘境定义；第一次成功进入后绑定该实例，人数满时拒绝，不另开实例。 |
| `return` | 使用进入秘境时记录的来源；不在秘境旅行中的实体不能使用。 |

实体必须碰到实际多边形区域，从正面和背面均可触发；凹口不传送。到达后有传送冷却，离开所有门面后才能再次触发。骑乘、载客和平台拒绝的跨维度传送不支持。

坐标门检查整个实体的碰撞、液体、危险方块、世界边界和支撑。先搜索已有安全位置；没有合适落点时，尝试在空白处铺一层泥土。普通玩家通常生成 3×3 平台，较大实体按体积扩大并留一格边。平台不会替换已有方块、排液体或挖开空间，必须完整位于世界边界内且不占用其他实体。无法安全生成时保留原位置。秘境入口、坐标门和回程共用这项兜底。

## 秘境令牌 {#秘境令牌}

令牌右键只召门，接触门面才传送，不消耗令牌。组件的 `preset` 选择形状与外观，`duration_ticks` 默认 `0`，表示门永久保留。再次使用优先复用令牌记住的同维度有效门，不续期。新召门有 20 tick 冷却，并受服务端玩家召门上限限制。

秘境实例销毁后，绑定该实例的入口失效；即使维度序号被重新使用，也不会把它当作原实例。门的存续时间与秘境实例时限各自独立。

秘境落点也检查安全，并在检查前准备目标区块。失败提示区分无支撑、碰撞、液体、危险方块、越界与区块未加载。管理员可用 `/secret_realm check <dimension>` 排查，或用 `/secret_realm anchor <dimension> <x> <y> <z>` 调整实例入口；详见[秘境管理命令](./commands/secret_realm.md)。

## 外观与限制 {#外观与限制}

样式可选 `rift`、`portal`，支持主色、边色、速度、边宽、柔光、边缘粒子和纹理缩放/旋转/偏移。主色 `-1` 自动按目标身份取色。门面完全不透明，先写入场景深度，再绘制后方的透明特效；不显示目的地的实时画面。

客户端配置「裂隙 → 自定义着色器」关闭后使用基础纯色门面。默认上限为每门 128 点、局部两轴各 32 格、每维度 1024 门、每子区块 32 门。上限由服务端统一校验。

## 命令 {#命令}

整棵 `/mxt rift` 子树需要 2 级 OP，`id` 为门 UUID，坐标与朝向在当前执行维度解释。建门、换目的地、改时长、开关、复制、变换与导出逐条见 [`/rift`](./commands/rift.md)。

## 蓝图与导出 {#蓝图与导出}

物品参数编辑器通过「保存参数」写入当时使用的物品；世界编辑器中，主手持裂隙锚时可用「写入主手裂隙锚」保存草稿蓝图。保存蓝图会清除先前潜行记录的目的地覆盖，以编辑器保存的目的地为准；之后仍可潜行记录新的目的地。导出预设用于 [rift 定义](../datapack/json/rift.md)，导出布局用于 [secret_realm.portals](../datapack/json/secret_realm.md)。可选相对玩家位置、当前维度本地目的地，或导出整个维度的布局（最多 128 门）。

导出先由服务端校验并复制到剪贴板；另点保存文件才写入游戏目录下的 `exports/mxt/rifts/`，同名文件不会覆盖。导入支持单门模板、预设或只含一扇门的布局。导出不包含成员、所有者、过期时刻或实例绑定。
