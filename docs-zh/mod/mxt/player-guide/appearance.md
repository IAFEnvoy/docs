# 界面外观

在 Jupiter 的 MiXianTu 客户端配置中，打开「界面外观 → 界面主题」选择主题。

| 主题 | 外观 |
| --- | --- |
| 宣纸朱砂（默认） | 暖色纸面、墨褐框线与朱砂标题。 |
| 青玉竹简 | 浅青玉色面板、竹青框线与深绿文字。 |
| 玄墨鎏金 | 深色墨玉面板、金色框线与浅色文字。 |

修改后关闭并重新打开界面即可生效，无需重启游戏。所有主题共用布局、字体和槽位尺寸。

主题适用于人物信息、灵气工作台、交易相关界面、裂隙编辑器与耗时监测界面。炼丹、锻器和画符工作站附属的 AUI 界面也使用此设置。原版界面、Saturn 轮盘、世界特效与原版物品提示框不受此设置影响。

灵气和资源自带的文字颜色会根据主题背景调整明度；物品、配方颜色与进度填色保留原有含义。主题使用 Minecraft 位图字体，无需安装额外字体。
