# 灵魂体

<span id="灵魂体" />

灵魂体是生物或玩家在生成瞬间留下的独立虚影。它保存原类型、UUID、名称、装备、背包、属性及能够随实体存档的模组数据；玩家还保留用于皮肤显示的档案。玩家统计、进度和其他模组独立数据库不属于这份快照。

默认在生物或玩家死亡时生成，快照在死亡掉落前取得。服务端配置「灵魂体 → 死亡后生成灵魂体」可以关闭自动生成。死亡掉落仍按原版规则处理。

命令显式生成不会杀死原实体、移动物品或改变玩家游戏模式，也不受死亡生成开关限制。

## 生成与回收 {#生成与回收}

以下命令需要 2 级管理员权限。省略目标时作用于自己。

```mcfunction
/mxt soul create
/mxt soul create @e[type=minecraft:sheep,sort=nearest,limit=1]
/mxt soul reclaim
/mxt soul reclaim @e[type=minecraft:sheep,sort=nearest,limit=1]
```

每个原实体同时只允许一个活跃灵魂体；已有有效灵魂体时，再次死亡不会重复生成。回收时选择原实体，且对应灵魂体所在区块需要已加载；命令不会强制加载它。

回收会删除灵魂体并清理原实体上的关联记录，不会恢复身体或把装备和背包复制回来。不要使用 `/kill` 代替回收，它不能清理原实体上的关联记录。

## 保留时间 {#保留时间}

服务端配置「灵魂体 → 灵魂体保留时间」默认 `6000` 游戏刻（20 TPS 时约 5 分钟），`0` 表示永久。死亡与命令生成的灵魂体都使用此设置，修改对已有灵魂体生效。

计时使用服务端游戏时间；区块卸载和玩家离线期间仍计时，服务器停机期间不计时。已加载灵魂体在 tick 中检查，到期后删除；卸载中的灵魂体在重新加载后的首次 tick 删除，不强制加载区块。

超时也会清理原实体的关联；原实体未加载时，在重新加载、登录或下次生成/回收时清理。超时属于自动清理，不触发可取消的回收事件，也不会复制回快照中的物品。

## 外观与保存 {#外观与保存}

虚影以半透明青白色显示生前身体轮廓，普通生物保留模型与变种，玩家显示档案对应的皮肤。它会轻微悬浮，不运行生前 AI，不受伤、不碰撞；所在区块正常卸载和保存。

完整快照只保存在服务端。客户端接收显示所需的外观信息，不接收背包和完整附件。装备数据保存在快照中，手持物品、名字、拴绳、火焰与独立粒子不绘制。使用专用渲染方式的实体或无法加载原外观的实体显示通用虚影。
