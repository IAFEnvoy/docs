# 服务端配置

<span id="服务端配置" />

本页收**服务端配置项**：它们按标签页分组，改完即时生效——服务端每次都读当前值，不缓存。它们**不是命令**，本页只写**服务端配置「标签页 → 条目」**，不写配置文件路径与键名。

客户端主题设置见[界面外观](./appearance.md)。

客户端配置「世界特效 → 场景深度增强」见[光束粒子](./light-beam.md#场景深度增强)。

本页配置由 MiXianTu 本体管理。三个工作站附属在 Jupiter 中各有自己的配置入口：[炼丹工作站](../addons/alchemy/config.md)、[锻器工作站](../addons/forging/config.md)、[画符工作站](../addons/talisman/config.md)。本页的丹毒、灵植和共享符箓物品配置在未安装附属时也生效。

## 符箓 {#符箓}

| 条目 | 默认 | 作用 |
| --- | --- | --- |
| 服务端配置「符箓 → 符笔容量」 | `4000` | 一支符笔能装多少颜料，单位＝像素弧长。一张 90×210 的符，笔画总长通常在 400–1200，所以默认约能描满 3–5 张。 |
| 服务端配置「符箓 → 一份颜料的点数」 | `1000` | 一份颜料（`#mxt:brush_pigment` 标签里的一个物品，默认只有朱砂）蘸进符笔后给多少颜料。 |
| 服务端配置「符箓 → 使用冷却」 | `20`（刻） | 徒手激发符箓后的物品栏冷却；`0` 不加冷却。冷却按物品算、对该玩家的所有符箓生效，冷却期间长按灌注也会被拒绝。 |

## 炼丹 {#炼丹}

| 条目 | 默认 | 作用 |
| --- | --- | --- |
| 服务端配置「炼丹 → 灵草单次补算上限（刻）」 | `24000` | 单次灵植生长结算最多补算多少游戏刻，范围 `20`–`2147483647`；与寿元显示换算无关。 |
| 服务端配置「炼丹 → 每秒丹毒自然消退」 | `0` | 已有丹毒的活跃实体每秒消退多少，必须是有限非负数。默认不消退；设成正数后每累计 20 个实体活跃 tick 减一次。离线不减，也不给没服过丹的实体建立附件。 |

## 灵魂体 {#灵魂体}

| 条目 | 默认 | 作用 |
| --- | --- | --- |
| 服务端配置「灵魂体 → 死亡后生成灵魂体」 | 开 | 生物和玩家死亡时保存快照并生成灵魂体；关闭不影响命令生成。 |
| 服务端配置「灵魂体 → 灵魂体保留时间」 | `6000`（游戏刻） | 20 TPS 时约 5 分钟；`0` 永久，范围 0–2147483647。区块卸载期间仍计时，到期后在实体 tick 中删除，修改对已有灵魂体生效。详见[灵魂体](./soul.md)。 |

## 调试 {#调试}

| 条目 | 默认 | 作用 |
| --- | --- | --- |
| 服务端配置「调试 → 调试模式」 | 关 | 放开只给复现问题用的入口：自己和自己交易、公式报错记全文堆栈、信息面板把放不下的条目报到日志、内部追踪日志逐条打。开发环境下强制开启。 |

## 命令别名 {#命令别名}

服务端配置的「命令别名」标签页里，每一项就是一个顶层别名命令——条目名就是命令本身，默认全开。关掉只移除顶层写法，`/mxt` 下的入口始终完整。别名清单见[命令](./commands.md)。

## 裂隙 {#裂隙}

| 条目 | 默认 | 作用 |
| --- | --- | --- |
| 服务端配置「传送门 → 每维度最多门数」 | `1024` | 每维度的门数量上限，1–4096。 |
| 服务端配置「传送门 → 每子区块最多重叠门数」 | `32` | 每个子区块内重叠门包围盒的上限，1–128。 |
| 服务端配置「传送门 → 每门最多顶点数」 | `128` | 每扇门顶点上限，3–128。 |
| 服务端配置「传送门 → 玩家召门上限」 | `8` | 令牌召门时统计已加载维度的有效自有门，1–128；管理员命令不受此项限制。 |
