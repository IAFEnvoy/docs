# `/trade`

<span id="trade" />

<div className="cmd-tree">

- `/trade <player>`

  向玩家发起交易请求。也可以写成 `/mxt trade <player>`。

</div>

对方接受后，双方分别打开交易界面，将物品放入各自的报价槽，并点击「确认」接受当前报价。

**确认绑定的是报价当时的样子。** 任何一侧在确认之后改动自己的报价（拿走、放入、shift 点击、数量变化），双方的确认都会作废，要重新按；只有两边都对着同一份报价按过确认，交易才会成交——所以不存在"趁对方按了确认再换东西"。

关闭界面即结束交易。按 Esc、切换至其他界面或服务端关闭时，报价槽中的物品均退还原持有者，同时解除双方的交易状态。
