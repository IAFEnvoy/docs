# 按键与轮盘

<span id="按键与轮盘" />

## 按键 {#按键}

| 按键 | 默认 | 作用 |
|---|---|---|
| 切换修炼模式 | `C` | 开始或停止修炼 |
| 打开 / 关闭人物信息面板 | `Z` | 打开人物信息面板 |
| 交换主手与背部武器槽位 | 未绑定 | 把主手物品与第一个 `back_weapon` 饰品槽互换 <br /> 交换按键遵循的槽位规则见 [Curios 槽位](./curios-slots.md) |
| 编辑 HUD 布局 | 右 `Shift` | 打开可拖动 HUD 元素的布局编辑器 |
| 轮盘选择 | `R` | 打开技能与灵气选择轮盘 |
| 轮盘使用 | `V` | 使用当前选择的技能/灵气 |
| 轮盘向左 / 向右翻页 | `←` / `→` | 在轮盘界面使用，切换主盘/其他副盘 |
| 飞行下降 | `X` | 驾驶飞行法器时的下降键 |
| 打开轮盘配置 | 未绑定 | 打开轮盘配置界面（等同于 `/wheel`） |
| 轮盘槽位 1–12 | 未绑定 | 使用当前页对应编号技能/灵气，等同于把指针指过去再按 `V` |

## 轮盘 {#轮盘}

轮盘由 Saturn 提供，MiXianTu 增加灵气、法器与契约内容。主盘是自己配置的12格；主手、副手、扩展装备与御兽铃根据当前内容生成从盘，超过12项自动分页。

按住 `R` 打开选择，指针方向决定格子；`V` 或左键使用。松开 `R` 只关闭，不使用。轮盘关闭时 `V` 使用记住的条目；左右方向键与滚轮切页。槽位快捷键作用于当前页，不局限于主盘。

## 轮盘配置 {#轮盘配置}

使用 `/wheel` 或 `/wheel configure` 打开配置；也可以为「打开轮盘配置」绑定按键。轮盘槽位1–12在「Saturn：轮盘槽位」分类，其余轮盘按键在「Saturn」主分类。

- 上方是**一个合并的候选池**，技能与灵气放在一起；内容多时滚轮或拖动滚动条查看。
- 下方是固定12格主盘，窄窗口会换行。左键选候选，再点槽位放入；再点已选候选可取消选择。右键槽位或未选候选时点击槽位可清空。
- 槽位底边的颜色条继续区分类别与状态。失效条目保留原位，以红色边框和提示说明，需手动清空。
- 关闭界面自动保存。从盘随当前装备与契约生成，不在这里编辑；只由双手物品提供的技能保留在各自从盘。
- 新存档的主盘为空，不自动填入条目；左侧技能栏在主盘12格全空时只隐藏主盘，自动识别的从盘技能继续显示且不留空白；配置至少一项后恢复主盘，清空后再次隐藏主盘。整张轮盘没有可用条目时，`R` 会给出提示。

Saturn 客户端配置的 `wheel.hold` 控制按住或切换打开，`wheel.scroll_switch` 控制滚轮翻页，`wheel.wrap_pages` 控制两端循环，默认均开启。

## 扩展/自定义 {#扩展-自定义}

内容模组可注册来源、条目类型、统一候选和额外 tooltip。接入方式见[轮盘条目](../java/wheel.md)。
