## 唤醒伙伴

| 对象 | 默认条件 |
| --- | --- |
| 剑 | 用剑击杀一只敌对生物。 |
| 镐 | 用合适的镐挖掘 `#psychic:attunement_ores` 中的一块矿石。 |
| 斧 | 持有一把符合条件的斧，可直接唤醒。 |
| 熔炉 | 自己放置熔炉，并让它完成一次烧炼。 |

唤醒物品时把它拿在主手，潜行并对着空气右键，或执行 `/psychic awaken`。唤醒熔炉时，用空主手对着它潜行右键，或执行 `/psychic awaken block`。

## 命名与点名

用 `/psychic list` 查看伙伴，执行 `/psychic select <序号或名字>` 选中一个。`/psychic name <名字>` 设置选中伙伴的主名，`/psychic alias add <别名>` 和 `/psychic alias remove <别名>` 管理别名。对着熔炉操作时，也可使用 `/psychic block name` 或 `/psychic block alias add`、`/psychic block alias remove`，后面加名字。

在聊天栏输入 `!<名字> <指令>` 或使用全角前缀 `！`。物品和方块的显示名也可以用来点名。多个伙伴同样匹配时，每个可操作的伙伴都会接单。用独立的名字可以只查询一个伙伴。查询方块伙伴时，也可以对准它发送 `!这台 状态`。已有选中的伙伴时也可省略名字，直接发送 `!状态`。

## 随身伙伴

| 指令 | 效果 |
| --- | --- |
| `!青锋 悬停` | 让名为「青锋」的伙伴飞到身旁。 |
| `!青锋 自由飞行` | 让它在附近自由活动。 |
| `!青锋 回背` | 召回这个伙伴。 |
| `!全队 回背` | 召回随身伙伴。 |
| `!青锋 取 8 个粗铁` | 让它飞到附近容器取料并送回背包。 |
| `!矿工 采掘` | 让名为「矿工」的镐采掘你对准且在交互距离内的方块。 |

飞行实体持有原物品。最多同时放出四个伙伴。通灵剑可持续协击。PvP 协击需要同一名玩家在 5 秒内对同一名对手造成两次伤害。`/psychic assist off` 和 `/psychic assist on` 控制选中伙伴的自动协击。

## 熔炉取料和烧炼

先把原料和燃料放在附近容器里。内置熔炉的搜索半径为 8 格。直接点名可以让交互距离内的熔炉接单。例如，`!一号炉 烧 8 个粗铁` 会取料、补充所需燃料，并把产物留在熔炉输出槽。

| 指令 | 效果 |
| --- | --- |
| `!一号炉 全烧 minecraft:raw_iron` | 逐批处理附近容器里的粗铁，每批产物送回对应的来源容器。 |
| `!一号炉 木桶里面有粗铁就帮我烧一下` | 设置持续规则，处理附近木桶后来放入的粗铁，也会送回产物。 |
| `!一号炉 停止自动烧炼` | 移除持续规则。已经开始的批次可以完成。 |
| `!一号炉 取消` | 取消正在取料的单批，或停止跟踪当前单批、停止后续批量取料。 |

持续规则在熔炉所在区块已加载、配置者在线且与熔炉处于同一维度时运行。原容器放不下产物或无法访问时，产物会留在熔炉。已通灵的容器由自身的行为主动出料。熔炉作为方块物品掉落时，会保留伙伴身份、名字和自动烧炼规则，重新放置后恢复。
