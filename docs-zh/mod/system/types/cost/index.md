sidebar_position: 0

System 向 Saturn 的费用类型注册表提供以下扩展，可嵌入商城、奖池和工坊的 `costs` 数组。

| 类型 | 用途 |
| --- | --- |
| [`system:currency`](./currency.md) | 从玩家的系统钱包扣除指定币种。 |

物品、Saturn 资源与组合费用见 [Saturn 费用](../../../../library/saturn/types/cost.md)，报价与支付生命周期见[费用与支付](../../../../library/saturn/guides/costs.md)。费用对象不是独立数据文件。
