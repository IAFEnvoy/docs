# 模组管理面板
## 数据来源

面板汇总以下来源的数据：

| 来源 | 内容 |
|--------|---------|
| CurseForge | 下载量 |
| GitHub | Issue、Pull Request |
| Codacy | 代码复杂度 / 维护难度（缓存在 `data/mods.db`） |

模组的**状态**、**颜色**、**加载器**以及版本支持 **emoji** 来自 `config/status_config.json` 和 `config/configuration.json`。现在已经没有分类分组——筛选仅通过**状态**和自由文本**搜索**完成。

## 列表视图

- **搜索**：匹配名称、ID、描述和类型标签
- **状态筛选**：按维护状态筛选（顺序来自 `status_config.json`）
- **排序**：按下载量、名称、状态顺序或 Issue+PR 数量排序

每张模组卡片从上到下依次显示：

1. 图标 + 名称
2. 描述——限制为 2 行；悬停显示完整文本
3. 标签块行——版本标签、维护状态、**维护难度**，然后是所有类型标签。该行限制为 2 行；超出部分显示为省略号，悬停该行可查看完整标签列表
4. 底部统计——CurseForge 下载量和 GitHub 未关闭的 Issue/PR 数

共同作者有意**不再**显示在卡片上——只在详情卡片中展示。

## 散点图视图

X 轴：维护难度，Y 轴：热度（下载总量的 log10）。

- 悬停圆点查看详情；点击打开详情卡片
- 图例按状态着色，可选择是否显示名称标签

## 详情卡片

点击卡片或散点图中的圆点打开。包含：

- 完整描述 + 状态 / 难度 / 标签块
- 带复制按钮的 **MOD ID** 和 **CF ID**
- CurseForge / GitHub / Wiki 链接
- 共同作者列表（仅在此处显示）
- 版本支持矩阵——每一行是一个 Minecraft 版本，每一列是一个加载器（Fabric / Forge / NeoForge…）。加载器表头通过 `colors.loader` 着色，单元格使用 `icons.versions` 中的 emoji（✅ 支持 / ⚠️ 部分支持 / …）
- Issue / PR 标签页（可筛选、分页），带有 🚀 派发到 AI 智能体的按钮

## 模组元数据编辑器（管理员）

可从 **🛠 Admin → Edit Mods** 或 `/mod-editor.html` 进入。两个独立滚动的面板占满整个视口：左侧是模组列表，右侧是编辑表单。

- **基本信息**：ID（可编辑；底层数字主键保持不变）、名称、图标上传（按模组 ID 存入数据库，因此 ID 重命名后仍能保留）、状态（下拉，文本按状态着色）、描述——保存前均为必填
- **平台与项目**：GitHub 仓库、CurseForge ID、Wiki URL、Java 包名、许可证（下拉或自由输入），架构 / 标签 / 共同作者为多选标签块字段，预填来自 `config/editor.yml`（见 [editor.yml](../configuration/editor-yml)）
- **版本支持**：版本行 × 加载器下拉，状态用 emoji 表示；可删除行，或至少保留一个空行
- **未保存的更改**：当前模组在左侧列表中显示为**斜体**，切换模组时会要求确认
- 保存 / 错误反馈以居中的绿色 / 红色提示条淡出显示

编辑后，可使用 **🛠 Admin** 菜单中的缓存项（**Clear database cache** 等）清除数据库映射缓存或按来源划分的 HTTP 缓存。
