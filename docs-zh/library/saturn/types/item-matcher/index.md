---
title: "物品匹配器"
sidebar_position: 0
---

用于 items 等 ItemMatcher 条目字段。多个条目取并集；支持物品、标签、通配、正则和原版材料。

| 类型 | 用途 |
| --- | --- |
| [`saturn:item`](./item.md) | 匹配一个物品注册 ID。 |
| [`saturn:tag`](./tag.md) | 匹配指定标签中的物品。 |
| [`saturn:wildcard`](./wildcard.md) | 按物品 ID 的通配模式匹配。 |
| [`saturn:regex`](./regex.md) | 按物品 ID 的正则表达式匹配。 |
| [`saturn:ingredient`](./ingredient.md) | 使用 Minecraft Ingredient 匹配物品。 |
