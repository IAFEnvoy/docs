---
title: "资源条渲染"
sidebar_position: 0
---

用于 ResourceBar.renderer，负责显示资源快照，不修改资源。颜色写 #RRGGBB。

| 类型 | 用途 |
| --- | --- |
| [`saturn:textured_bar`](./textured_bar.md) | 使用背景与填充贴图绘制资源条。 |
| [`saturn:segmented_bar`](./segmented_bar.md) | 使用多个色块表示资源量。 |
| [`saturn:radial_bar`](./radial_bar.md) | 在指定角度范围内绘制环形进度。 |
| [`saturn:text_only`](./text_only.md) | 用格式文本显示资源值。 |
| [`saturn:boss_bar`](./boss_bar.md) | 使用指定贴图的 Boss 血条样式。 |
| [`saturn:missing`](./missing.md) | 表示没有可用实现或取值。 |
