ResourceBar.context 使用字符串 ID，而不是带 type 的对象。上下文是否被实际绘制仍取决于宿主界面。

| 类型 | 用途 |
| --- | --- |
| [`saturn:self_hud`](./self_hud.md) | 显示当前玩家自身资源。 |
| [`saturn:target_overlay`](./target_overlay.md) | 为当前目标提供资源显示上下文。 |
| [`saturn:boss_overlay`](./boss_overlay.md) | 为 Boss 资源条提供显示上下文。 |
