---
title: "实体取值器"
sidebar_position: 0
---

EntityValueGetter 的完整参数决定查询身份。只读取传入视图或已采集快照；缺失与已知的 0、false、空集合不同。

| 类型 | 用途 |
| --- | --- |
| [`saturn:attribute`](./attribute.md) | 从已采集属性中读取指定属性的基础值或有效值。 |
| [`saturn:resource`](./resource.md) | 从已采集资源中读取指定资源的当前值或上下限。 |
| [`saturn:effect`](./effect.md) | 读取指定状态效果的等级或时长。 |
| [`saturn:score`](./score.md) | 读取指定记分项的分数。 |
| [`saturn:abilities`](./abilities.md) | 读取实体持有的技能信息。 |
| [`saturn:absorption`](./absorption.md) | 读取实体的伤害吸收生命值。 |
| [`saturn:advancements`](./advancements.md) | 读取已采集的玩家成就信息。 |
| [`saturn:air`](./air.md) | 读取实体剩余空气值。 |
| [`saturn:attributes`](./attributes.md) | 读取已采集的属性列表。 |
| [`saturn:carried_item`](./carried_item.md) | 读取玩家光标当前携带的物品。 |
| [`saturn:effects`](./effects.md) | 读取实体当前的状态效果列表。 |
| [`saturn:ender_chest`](./ender_chest.md) | 读取已采集的玩家末影箱内容。 |
| [`saturn:equipment`](./equipment.md) | 读取实体装备槽信息。 |
| [`saturn:experience`](./experience.md) | 读取玩家经验点数、等级和进度。 |
| [`saturn:food`](./food.md) | 读取玩家饥饿值、饱和度和消耗度。 |
| [`saturn:game_mode`](./game_mode.md) | 读取玩家的游戏模式。 |
| [`saturn:health`](./health.md) | 读取实体当前生命值。 |
| [`saturn:inventory`](./inventory.md) | 读取已采集的玩家背包内容。 |
| [`saturn:location`](./location.md) | 读取实体位置和维度。 |
| [`saturn:max_health`](./max_health.md) | 读取实体最大生命值。 |
| [`saturn:profile`](./profile.md) | 读取玩家 UUID 与名称。 |
| [`saturn:resources`](./resources.md) | 读取已采集的 Saturn 资源列表。 |
| [`saturn:scores`](./scores.md) | 读取已采集的计分板分数。 |
| [`saturn:selected_slot`](./selected_slot.md) | 读取玩家当前选中的快捷栏槽位。 |
| [`saturn:statistics`](./statistics.md) | 读取已采集的玩家统计信息。 |
| [`saturn:team`](./team.md) | 读取已采集的计分板队伍信息。 |
