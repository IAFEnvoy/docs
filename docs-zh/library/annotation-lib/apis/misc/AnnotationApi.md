# AnnotationApi <Utility/>

这是主要 API 的提供类。

## `register`

手动将你的类注册到加载系统。

## `registerProcessor`

将你自己的自定义处理器注册到加载系统。

## `getConfig`

获取通过 [@ConfigFile](./../annotations/config/ConfigFile) 注册的配置。

## `registerHotkeyHandler`

为通过 [@AutoNetwork](./../annotations/registration/AutoNetwork) 注册的快捷键注册处理器。
