## 如何贡献

本文档允许任何人通过 GitHub 上的 PR 参与贡献。但有以下几点需要注意：

1. 所有文档（包括冰火社区版）都直接在[主仓库](https://github.com/IAFEnvoy/docs)中维护。请将文档修改提交到该仓库。

2. 非文本文件引用的要求：

- 文件应尽可能小。（例如图片使用 `webp` 格式）
- 图片和其他资源建议使用相对路径。

3. 如果希望长期维护，请在 GitHub 或 Discord 上向我申请仓库权限。
