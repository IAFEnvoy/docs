# Puffish Skills

:::caution Unstable
This integration is newly implemented and currently unstable.
:::

Enabled when Puffish Skills is installed.

## `origins_integration:power`

[Puffish Skills Reward Type](https://www.curseforge.com/minecraft/mc-mods/puffish-skills)

Registers an Origins power reward type. Reward data contains a required `power`
identifier and an optional `source` identifier. The specified Origins power
remains granted while the reward count is positive.
